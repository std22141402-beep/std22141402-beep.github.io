# 🛒 سوبرماركت برو

تطبيق ويب لإدارة مواد المحل: أسعار الجملة والمفرد، الكميات، وقائمة النقص — مع قارئ باركود بالكاميرا.
يشتغل على الموبايل والكمبيوتر، يتثبت على الشاشة الرئيسية مثل أي تطبيق، ويشتغل بدون إنترنت.

**الرابط:** https://std22141402-beep.github.io/supermarket/

## المميزات

- **فحص السعر بالباركود**: وجّه الكاميرا على أي مادة ويطلعلك سعر المفرد والجملة والكمية فوراً
- **قائمة المواد**: باركود، اسم، فئة، سعر جملة (مع عدد القطع بالكارتونة)، سعر مفرد، الكمية، وحد التنبيه
- **حساب الربح تلقائياً**: كلفة القطعة وربحها ونسبة الربح
- **قائمة النقص**: إضافة يدوية أو بالباركود، اقتراح تلقائي للمواد اللي قاربت تخلص، ولما توصل البضاعة الكمية تنضاف للمخزون
- **إرسال قائمة النقص للمورد** بالواتساب، أو نسخها، أو طباعتها
- **يدعم أجهزة الباركود** (USB / بلوتوث) على الكمبيوتر
- **Excel**: تصدير المواد واستيرادها من ملف CSV
- **نسخ احتياطي** واسترجاع بملف
- **وضع داكن** وواجهة عربية بالكامل
- **يشتغل بدون إنترنت** بعد أول فتح

## الملفات

| الملف | شنو يسوي |
|---|---|
| `index.html` | التطبيق كامل |
| `manifest.webmanifest` | يخلي التطبيق يتثبت على الشاشة الرئيسية |
| `sw.js` | يخلي التطبيق يشتغل بدون إنترنت |
| `icon-192.png` `icon-512.png` `icon-maskable.png` `apple-touch-icon.png` | أيقونات التطبيق |

## طريقة النشر على GitHub Pages (مجاناً)

### من الموبايل
1. افتح **github.com** وسجّل حساب (أو سجّل دخول)
2. اضغط **+** فوق ← **New repository**
3. اسم المستودع: `supermarket` ← اختار **Public** ← اضغط **Create repository**
4. بالصفحة الجديدة اضغط **uploading an existing file** (أو Add file ← Upload files)
5. اختار كل الملفات (بعد ما تفك الضغط عن الـ zip) ← اضغط **Commit changes**
6. روح **Settings** ← **Pages**
7. تحت **Branch** اختار `main` و `/ (root)` ← **Save**
8. انتظر دقيقة أو دقيقتين، وراح يطلع الرابط:
   `https://اسم-حسابك.github.io/supermarket/`

### من الكمبيوتر
نفس الخطوات، بس بالخطوة 5 تقدر تسحب كل الملفات وتفلتها مرة وحدة.

## ملاحظات مهمة

- **الكاميرا تحتاج رابط https** — يعني تشتغل من رابط GitHub Pages، وما تشتغل إذا فتحت `index.html` من الملفات مباشرة
- أول مرة تفتح الكاميرا، المتصفح يطلب إذن ← اضغط **سماح**
- **البيانات محفوظة على نفس الجهاز والمتصفح**. إذا تريد تنقلها لجهاز ثاني: الإعدادات ← حفظ نسخة احتياطية، وبالجهاز الثاني: استرجاع نسخة احتياطية
- احفظ نسخة احتياطية بين فترة وثانية (التطبيق يذكّرك كل أسبوع)

## استيراد المواد من Excel

1. من الإعدادات ← **تنزيل نموذج جاهز**
2. افتحه بالإكسل واملأ موادك (كل مادة بسطر)
3. احفظه بصيغة **CSV UTF-8**
4. من الإعدادات ← **استيراد مواد من Excel** واختار الملف

الأعمدة: الباركود، اسم المادة، الفئة، سعر الجملة، عدد القطع بالجملة، سعر المفرد، الكمية، حد التنبيه، ملاحظات.
إذا المادة موجودة (نفس الباركود) تتحدث، وإذا جديدة تنضاف.

## تحديث التطبيق

إذا عدّلت أي ملف وسويت Commit، التحديث يوصل للمستخدمين تلقائياً بأول فتح مع إنترنت.
للتحديثات الكبيرة غيّر رقم `VERSION` بأول سطر في `sw.js`.
