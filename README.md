# سالكة 🧭 — تطبيق ملاحة عراقي

تطبيق ملاحة يشتغل على أي موبايل (أندرويد وآيفون) من المتصفح، وينضاف للشاشة الرئيسية مثل أي تطبيق.

## شنو يسوي

### جديد بالإصدار 1.2 ✨
- **هوية فخمة «عالم ثاني»**: ثيم «ملكي» (ذهبي على كحلي)، زجاج شفاف، شعار ذهبي جديد، وشاشة افتتاحية بسماء نجوم.
- **افتتاحية من الفضاء**: تفتح التطبيق تشوف الكرة الأرضية بغلافها الجوي، وتطير الكاميرا لموقعك.
- **سماء وأفق ومباني ثلاثية الأبعاد** تتلون حسب ارتفاعها، وخط طريق مضيء.
- **ازدحام ملوّن على الشوارع** (أحمر/برتقالي/أصفر) من سرعات السواق الحقيقية، ويدخل بحساب أسرع طريق ووقت الوصول.
- **أكثر من وجهة**: أضف لحد 4 محطات بالطريق، ويعلن «وصلت للوقفة الأولى» ويكمل.
- **تنعيم الـGPS** (فلتر كالمان): يشيل الارتجاج بدون ما يأخر السيارة.
- **خدمات سالكة**: مكان جاهز للتكسي والعقارات (بالتحديثات الجاية).

### الأساسيات

- **ملاحة صوتية خطوة بخطوة** باللهجة العراقية («لِف يمين»، «بالفلكة اطلع من الفرع الثاني»، «سوّي يوتيرن») أو بالفصحى.
- **إعادة حساب فورية**: إذا غيّرت طريقك يكتشفه خلال ثواني ويطلب طريق جديد بنفس اتجاه سيارتك، فما يطلب منك تسوي يوتيرن بلا داعي.
- **حركة سلسة**: السيارة تتحرك على الطريق بسلاسة 60 إطار بالثانية، مع توقع موقعها بين قراءات الـGPS، والكاميرا تقرّب وتبعّد حسب سرعتك.
- **ما يعيد الحساب بالغلط**: ما يتأثر بارتجاج الـGPS، ولا بالشوارع الموازية، ولا إذا كنت بموقف سيارات بالبداية.
- **بلاغات الطريق المشتركة** مثل ويز: ازدحام، حادث، شرطة، طسّة، مي أمطار، طريق مسدود، كاميرا. بلاغك يوصل لكل المستخدمين فوراً، وينبهك قبل ما توصل لبلاغاتهم، ويسألك «بعده موجود؟».
- **يتجنب الازدحام**: إذا أكو بلاغ ازدحام أو طريق مسدود على طريقك، يقترح طريق أسرع ويحوّلك تلقائياً.
- **الحارات**: يبين لك أي حارة تلزم قبل المنعطف (إذا المعلومة موجودة بالخريطة).
- **بحث بالعربي** عن أي مكان بالعراق، أو بالإحداثيات، أو بالضغط المطول على الخريطة.
- **قريب مني**: محطات وقود، مطاعم، مستشفيات، صيدليات، مصارف، كراجات، تصليح سيارات، جوامع.
- **أماكني**: البيت والشغل والمفضلة، وآخر الأماكن.
- **ألوانك**: 5 ثيمات جاهزة (دجلة، نخيل، تمر، ليل بغداد، جوري) + لون تختاره أنت + لون خط الطريق + شكل السيارة.
- **وضع ليلي تلقائي** حسب غروب الشمس الحقيقي بموقعك.
- **تنبيه السرعة**، ومشاركة وقت الوصول، وإبقاء الشاشة شغالة أثناء الملاحة.
- **تجربة القيادة**: تكدر تجرب الملاحة كاملة وأنت بالبيت، وتنحرف عن الطريق حتى تشوف إعادة الحساب.
- **يشتغل بدون نت** للأجزاء اللي شفتها من الخريطة قبل (النسخة الكاملة).

## شلون تشغّله على موبايلك (من الموبايل بس، 5 دقايق)

الموقع (GPS) ما يشتغل إلا من رابط **https**، فلازم ترفع التطبيق على استضافة مجانية. أسهل طريقة هي GitHub Pages:

1. افتح **github.com** وسوّي حساب (مجاني).
2. اضغط **+** ← **New repository** ← سمّيه `salka` ← اختار **Public** ← **Create repository**.
3. اضغط **uploading an existing file** (أو Add file ← Upload files) ← اختار ملف **`index.html`** من مجلد `dist` ← **Commit changes**.
4. روح لـ **Settings** ← **Pages** ← تحت Branch اختار `main` و `/ (root)` ← **Save**.
5. بعد دقيقة أو دقيقتين يصير رابطك: `https://اسمك.github.io/salka/`
6. افتحه بكروم ← اسمح بالموقع ← من القائمة ⋮ اختار **«إضافة إلى الشاشة الرئيسية»**. هسه صار عندك تطبيق.

> **النسخة الكاملة** (تشتغل بدون نت وتنثبت بأيقونتها): ارفع **كل** الملفات (index.html, css, js, icons, sw.js, manifest.webmanifest) بنفس الترتيب. من الحاسبة تكدر تسحب المجلد كله لصفحة الرفع مرة وحدة.

## الازدحام المباشر — شلون يشتغل

- كل سيارة تستخدم الملاحة الحقيقية ترسل **كل 30 ثانية** رسالة صغيرة: «هذا المقطع مشيته بكذا من سرعته الطبيعية».
- الرسالة **ما بيها اسم ولا رقم جهاز** — بس إحداثيات المقطع ونسبة السرعة. ووضع «تجربة القيادة» ما يرسل شي.
- الكل يستلم العينات ويلوّن الشوارع: أحمر = واقف، برتقالي = بطيء، أصفر = مزدحم شوية. العينة تبقى 20 دقيقة.
- الطرق المزدحمة تنحسب أبطأ عند اختيار الطريق، ووقت الوصول يزيد حسب الزحمة اللي قدامك، وإذا صارت زحمة كبيرة قدامك يقترح طريق أسرع.
- تكدر تطفي الإرسال أو العرض من الإعدادات. الإعدادات بملف `js/config.js` تحت `TRAFFIC`.

## البلاغات المشتركة (شغالة تلقائياً)

البلاغات تنشارك بين كل المستخدمين **فوراً وبدون أي إعداد**، عن طريق خادم [ntfy.sh](https://ntfy.sh) المجاني:
بلاغك يوصل لكل من فاتح التطبيق خلال ثانية، والتصويت («بعده موجود؟») والحذف كذلك. وإذا النت مقطوع، البلاغ ينحفظ وينرسل أول ما يرجع.

- الخادم يحتفظ بالبلاغات **12 ساعة**، وهذا يكفي للازدحام والحوادث والشرطة.
- إذا تريد شبكة بلاغات خاصة بتطبيقك بس، غيّر `ntfyTopic` بملف `js/config.js` لاسم خاص بيك.

### ترقية اختيارية: قاعدة Firebase خاصة بيك

إذا كبر التطبيق وتريد تحكم كامل (بلاغات تبقى أطول، وحماية من الإزعاج):

1. افتح **console.firebase.google.com** ← Add project.
2. **Build ← Realtime Database ← Create database**.
3. بتبويب **Rules** الصق هذا واضغط Publish:

```json
{
  "rules": {
    "salka": {
      "reports": {
        "$day": {
          ".read": true,
          "$id": {
            ".write": "!data.exists() && newData.exists()",
            ".validate": "newData.hasChildren(['k','x','y','t','d']) && newData.child('k').isString() && newData.child('k').val().length <= 20 && newData.child('x').isNumber() && newData.child('y').isNumber() && newData.child('t').isNumber() && newData.child('t').val() <= now + 60000 && newData.child('d').isString() && newData.child('d').val().length <= 40",
            "v": {
              "$dev": {
                ".write": true,
                ".validate": "newData.val() === 1 || newData.val() === -1"
              }
            }
          }
        }
      }
    }
  }
}
```

4. بالتطبيق: **الإعدادات ← البلاغات المشتركة** ← الصق رابط القاعدة ← **فحص رابط Firebase**. التطبيق يتحول لها تلقائياً.

## تحويله لتطبيق APK (أندرويد) أو للمتجر

بعد ما يصير عندك رابط (مثل `https://اسمك.github.io`):

1. افتح **pwabuilder.com** والصق رابطك ← **Start**.
2. اضغط **Package for stores** ← **Android** ← **Generate**.
3. ينزل عندك ملف مضغوط بيه:
   - ملف **APK** تكدر تنصبه على أي موبايل أندرويد مباشرة.
   - ملف **AAB** إذا تريد تنشره على Google Play (يحتاج حساب مطوّر بـ 25 دولار مرة وحدة).
   - ملف **assetlinks.json**: ارفعه بمجلد `.well-known` بالموقع حتى يختفي شريط الرابط من التطبيق.

## شلون تضيف أدواتك وتغيّر الألوان

كل الإعدادات المهمة بملف واحد: **`js/config.js`**

| تريد… | غيّر |
|---|---|
| نوع بلاغ جديد | سطر جديد بـ `REPORT_TYPES` (الاسم، الإيموجي، اللون، مدة البقاء، تأثيره على الطريق) |
| ثيم ألوان جديد | سطر جديد بـ `THEME_PRESETS` (الثيم «ملكي» مثال على تدرج ذهبي ولافتة كحلية) |
| تصنيف جديد بـ «قريب مني» | سطر جديد بـ `CATEGORIES` (فلتر Overpass مثل `["amenity"="car_wash"]`) |
| اسم التطبيق | `APP.name` |
| حساسية إعادة الحساب | `NAV.offRouteMin` و `NAV.offRouteMax` |
| ألوان الخريطة نفسها | `MAP_PALETTES` بملف `js/theme.js` |
| كلمات التعليمات الصوتية | `js/instructions.js` (قسم `iraqi` و `msa`) |
| شكل الواجهة | متغيرات الألوان بأول ملف `css/app.css` |

بعد أي تعديل، إذا تستخدم ملف واحد: شغّل `python3 tools/build-single.py` حتى يتحدث `dist/index.html`.
إذا تستخدم النسخة الكاملة: غيّر رقم `VERSION` بملف `sw.js` حتى يوصل التحديث للمستخدمين.

## حدود لازم تعرفها (بصراحة)

- **الازدحام المباشر**: ويز يعرف الازدحام من ملايين السواق. سالكة يعرفه من **بلاغات مستخدميه** بس، فكل ما زاد المستخدمين صار أدق.
- **الخوادم المجانية** (OSRM و Photon و OpenFreeMap) ممتازة للتجربة ولعدد محدود من المستخدمين. إذا التطبيق انتشر بالآلاف، لازم تشغّل خادم OSRM خاص بيك (مجاني ومفتوح المصدر، يحتاج سيرفر بسيط وخريطة العراق من Geofabrik).
- **دقة الخريطة** تعتمد على OpenStreetMap. إذا لكيت شارع ناقص أو غلط، تكدر تصلحه بنفسك على openstreetmap.org ويتحدث عند الكل.
- **المتصفح بالخلفية**: إذا طفّيت الشاشة أو طلعت من التطبيق، المتصفح يوقف الـGPS. التطبيق يخلي الشاشة شغالة أثناء الملاحة، فخليه قدامك.
- **متجر Google Play / App Store**: هذا تطبيق ويب. حتى تنشره بالمتجر تكدر تغلّفه بأداة **Capacitor** بدون ما تغيّر الكود.
